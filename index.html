OpenSpot

A shared payload stack for Spot.

OpenSpot combines modular sensor mounts, Jetson compute, field networking, and a handheld operator interface.

The current release includes the mechanical designs and reference network. Electronics documentation and the Operator package are still in progress.

Reference architecture

Robot-to-operator connectivity

Spot, the Jetson, sensors, and the payload radio share a 2.5 GbE network. A wireless bridge connects the robot to the operator.

System

Hardware, networking, and control

Modular hardware

Mounts for compute, LiDAR, radios, electronics, and swappable sensors.

Edge compute

Jetson Orin compute for perception, mapping, logging, and autonomy.

Field networking

Onboard switching and a wireless bridge to the operator.

OpenSpot Operator

A Steam Deck interface and Jetson daemon for control, telemetry, video, and diagnostics.
